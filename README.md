# warriors-of-the-night
Warriors of the Night

## Test gry

`node test_gry.mjs` przechodzi wszystkie plansze w Chrome bez okna i zgłasza błędy JavaScriptu.
Opcje: `--tury` (także tura wrogów), `--zrzuty` (zrzuty do `zrzuty_testu/`), `--plansza=las,parow`.
